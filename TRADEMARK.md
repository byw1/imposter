## What this means for forks

You may fork, modify and redistribute the code under AGPL-3.0. If you do, you
must rename.

**Forks must:**

- Choose a different app name, and not one confusingly similar to Imposter: Game Night
- Replace Shade, the icon and any wordmark with their own
- Change the bundle identifier from `com.bywilliaml.imposter` (and any ID this project ships under)
- Change the URL scheme from `imposter://`
- Not present the fork as an official release of this app

**Forks may:**

- State factually that the work is derived from Imposter: Game Night, for example "based on
  Imposter: Game Night" or "a fork of Imposter: Game Night", provided this does not suggest endorsement
  by or affiliation with the copyright holder

The intent is not to restrict the code. It is to keep users from installing
something they believe is this app when it is not.

## Prior art and other games

Imposter: Game Night implements a hidden-word social deduction game: everyone
but one player shares a secret word, and the table tries to find the one who
doesn't. The mechanic is a public-domain party game and is not claimed by
anyone. This project is not affiliated with, endorsed by, or derived from any
commercial game in the category, and uses none of their names, words, artwork or
visual identity.
