# Imposter

**The party game where everyone knows the secret word, except one of you.**
Pass one phone round the table. Everyone peeks at their card: the word, or
"Imposter". Go round giving one-word clues. Too obvious and you've handed the
imposter the answer; too vague and you look like the imposter. Then argue, vote,
and see who it really was. Caught imposters get one guess at the word to steal
the win.

For 3 to 12 players, friends and family. Fully offline: no accounts, no ads,
no subscriptions, nothing to download after install.

Imposter is the sibling of [Charades](https://github.com/byw1/charades): same
stack, same camera-app look, same sticker mascot style, built from the Imposter
design system.

## A round, start to finish

1. **Set up once.** Add everyone in the order you're sitting. Pick topics and
   house rules: 1 to 3 imposters (or a surprise), whether imposters see the
   topic, how many clues each, the talk timer, and how you vote.
2. **Pass and peek.** The phone goes round. Each player's name fills the
   screen; they *hold* the big pill and their card turns over; they let go and
   it's face down again. Every card looks, sounds and buzzes the same, in or
   imposter.
3. **Clues.** The phone sits in the middle and calls each player in turn:
   *"Maya, one word."* The start seat is random every round.
4. **Talk it out.** A quiet timer bar, and a nudge now and then
   (*"Who was too vague?"*). +30 seconds if it's getting good.
5. **Vote.** Either everyone points on a 3-2-1 and the host taps who got the
   most fingers, or a secret vote where the phone goes round and the votes are
   counted out one dot at a time. Ties get a revote between the tied players.
6. **Reveal.** Drumroll, the sticker trembles, the censor bar slides off: *in*,
   or *the imposter*.
7. **The steal.** A caught imposter picks the secret word from a handful of
   words in the same topic. Right, and they steal the win.
8. **Verdict and recap.** The screen turns blue (*Caught!*) or Shade's red
   (*Got away*, *Stole it*), then the word, who scored, and tonight's table.

## Features

- **12 topics, 600 words, all free**: Food, Animals, Places, Jobs, Movies & TV,
  Sports, Around the house, Music, Party, Fantasy, School and Travel.
- **Make your own topics**: inside jokes, your town, your group chat. Paste a
  list from anywhere.
- **House rules that stick**: imposter count (or 🎲 surprise), hint on or off,
  1 to 3 clues each, talk timer from off to 3 minutes, point or secret voting.
- **Points and bragging rights**: tonight's table after every round, and on the
  You page every night on this phone: best liar, best detective, word thief.
- **Resume anything**: the game saves at every step. Close the app mid-vote and
  it picks up on the same screen.
- **Shade**, the mascot: Dex's red cousin in dark shades, with a `?` card on
  its forehead. It sneaks peeks over its shades, gasps at the vote and gets its
  shades knocked crooked when caught.
- Synthesised sound effects, haptics, dark and light themes, and reduced
  motion respected everywhere.

## How it's built

| | |
| --- | --- |
| **App** | Expo SDK 57, React Native 0.86, React 19, Expo Router |
| **Language** | TypeScript, strict |
| **State** | Zustand stores, saved on the phone with `expo-sqlite/kv-store` |
| **Sound** | `expo-audio`; ten effects generated by `spec/generate-sounds.js` |
| **Tests** | Jest: pure game logic under `ts-jest` |

- **Pure game rules.** Dealing, voting, scoring, stats and the round's state
  transitions live in `src/game` as plain TypeScript, with no React or Expo
  imports (enforced by a lint rule) and unit tests for every rule.
- **Offline, enforced.** An ESLint rule bans `fetch`, `XMLHttpRequest`,
  `WebSocket` and network-capable modules, and a test scans the source and the
  build config for the same, so it can't be switched off with a comment.
- **Nothing leaks a role.** The RoleCard is the topic colour for everyone, the
  reveal sound and haptic are identical, and the card goes face down the instant
  the thumb lifts.
- **Saved data is checked on the way back in.** Everything read from storage
  goes through `src/game/validate.ts`, so an old or damaged save is repaired or
  dropped rather than crashing the app.

## Run it

You need Node 22+ and an iPhone with [Expo Go](https://expo.dev/go).

```sh
npm install
npm start          # scan the QR code with your iPhone's camera
```

Checks:

```sh
npm run typecheck
npm run lint
npm test
```

To install it as a real app, or ship it: `npm run phone` and `npm run store`
(EAS Build), the same as Charades. See [DEPLOY.md](./DEPLOY.md).

## Project layout

```
app/                Screens (Expo Router)
  new/              Players and house rules
  round/            deal → clues → talk → vote → reveal → guess → verdict → recap
  topics/           A topic's words, and the topic editor
src/
  game/             Pure game logic: no React, no React Native
  topics/           The bundled topics, and parsing pasted word lists
  storage/          The on-phone key-value store
  ui/               Components, design tokens, Shade the mascot
  home/             The three swipeable home pages: Topics, Play, You
  round/            Shared round chrome
  media/            Sound effects
  hooks/            Stores and settings
assets/             App icon, splash, sounds
spec/               Sound generator
```
